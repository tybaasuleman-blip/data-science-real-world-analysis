# 📊 Data Science Assignment Project

This repository contains my Data Science assignment where I analyzed three real-world datasets:
- Rainfall Data (Climatology)
- Mobile Market Data (E-commerce / Tech Market)
- Historical Birth Data (Demographics)

The project demonstrates how raw data can be cleaned, analyzed, and transformed into meaningful insights using Python and data science techniques.

---

## 📌 Project Overview

In this project, I:
- Cleaned and preprocessed raw datasets
- Converted unstructured data into usable numeric format
- Applied Exploratory Data Analysis (EDA)
- Used visualization techniques (heatmaps, bar charts, regression plots)
- Extracted patterns, trends, and correlations
- Generated insights for real-world decision-making

All three datasets were handled in a single coding notebook to optimize time and workflow efficiency.

---

## 🌧️ 1. Climatological Rainfall Analysis

### Objective:
Analyze rainfall patterns across provinces and time periods.

### Key Methods:
- Mean Absolute Deviation (MAD)
- Spatiotemporal analysis

### Key Insights:
- Punjab and Sindh show high rainfall volatility in August
- Northern regions are more stable
- Balochistan remains consistently dry

### Outcome:
Rainfall variability is more important than average rainfall for flood risk prediction.

---

## 📱 2. Mobile Market Intelligence

### Objective:
Understand what drives mobile pricing and customer satisfaction.

### Key Methods:
- Feature engineering (e.g., converting “128 GB” into numeric values)
- Correlation analysis

### Key Insights:
- RAM and storage strongly affect price
- Weak relationship between specs and customer ratings
- Brand value (Apple, Samsung) has stronger influence than discounts

### Outcome:
Brand trust and user experience matter more than price competition.

---

## 👶 3. Historical Birth Trends Analysis

### Objective:
Analyze long-term population patterns and data reliability.

### Key Methods:
- Rolling averages
- Density heatmaps
- Sex ratio analysis

### Key Insights:
- Seasonal birth clustering in late summer and early autumn
- Data inconsistencies in earlier decades (1970s–80s)
- Improved reporting accuracy over time

### Outcome:
Rolling averages provide better forecasting for long-term planning.
